# 💬 Mini WhatsApp

A simple **WhatsApp-like chat application** built with **Node.js, Express.js, MongoDB, Mongoose, and EJS**.

## ✨ Features

* 💬 View all chats
* ➕ Create new chats
* ✏️ Edit chats
* 🗑️ Delete chats
* 🕒 Display date & time
* 🍃 Store chats in MongoDB

## 🛠️ Tech Stack

**Node.js | Express.js | MongoDB | Mongoose | EJS | Method-Override**

## 🎯 Concepts Used

* CRUD Operations
* Express Routing
* MongoDB & Mongoose
* EJS Templating
* Form Handling
* REST-style Routes
